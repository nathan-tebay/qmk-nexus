# Keyboard Feature Coverage Report

Generated by scanning 2,444 keyboard detail files from the QMK Nexus index (3,712 total keyboards, 2,444 with feature metadata).

---

## Methodology

Each keyboard is scored on 13 features tracked by the QMK Nexus feature toggle system:

| Feature | Group | Weight | Prevalence |
|---------|-------|--------|------------|
| Extra Keys | Input | 0.5 | 95.6% |
| Boot Magic | Input | 0.5 | 79.4% |
| Mouse Keys | Input | 0.5 | 73.8% |
| N-Key Rollover | Input | 0.5 | 61.9% |
| Encoder | Input | 1.5 | 17.7% |
| Pointing Device | Input | 3.0 | 0.8% |
| RGB Light | Lighting | 1.0 | 32.5% |
| RGB Matrix | Lighting | 2.0 | 11.6% |
| Backlight | Lighting | 1.0 | 14.4% |
| OLED Display | Display | 2.0 | 6.2% |
| Audio | Advanced | 3.0 | 2.1% |
| Console | Debug | 1.5 | 17.8% |
| Unicode | Advanced | 2.0 | 2.7% |

Rarer features carry higher weights. Maximum possible score is ~22.5.

## Feature Prevalence Summary

The most common features (Extra Keys at 95.6%, Boot Magic at 79.4%, Mouse Keys at 73.8%) are baseline QMK capabilities. The differentiating features are:

- **Encoder** (17.7%) -- The most common "premium" feature
- **Console** (17.8%) -- Debug output, moderately common
- **Backlight** (14.4%) -- Simple PWM backlight
- **RGB Matrix** (11.6%) -- Per-key RGB, less common than rgblight
- **OLED Display** (6.2%) -- Screen support
- **RGB Light** (32.5%) -- Underglow strip lighting
- **Unicode** (2.7%) -- Unicode input support
- **Audio** (2.1%) -- Piezo/speaker output
- **Pointing Device** (0.8%) -- Trackball/trackpad (rarest)
